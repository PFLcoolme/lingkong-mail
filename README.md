# 空灵邮箱（Kongling Mail）

一款面向 Linux 桌面的本地邮件管理客户端。所有邮件正文与附件缓存在本机 SQLite 数据库中，支持离线浏览与全文检索；凭据使用系统密钥环（libsecret）加密保存。

## 界面设计

- **彻底无边框**：移除了系统原生标题栏，使用自绘标题栏（可拖动、双击最大化、最小化/最大化/关闭按钮），窗口带圆角与柔和投影
- **毛玻璃质感**：面板使用 `backdrop-filter` 高斯模糊 + 半透明背景 + 细腻描边，层次分明
- **简约黑白灰 / 白色主调**：中性色板，近黑作为强调色，默认浅色主题（可切换深色或跟随系统）
- 组件基于 **MUI (Material UI)** 统一构建，全部交互控件具备键盘可达性与 ARIA 标注
- 若某些 Linux 合成器下透明窗口表现异常（发黑），可在「设置 → 常规」中关闭「毛玻璃透明背景」

## 功能一览

- **多账户管理**：可同时添加任意数量的邮箱，支持启用/停用、颜色标识、独立签名
- **全部收件箱**：把所有账户的收件箱聚合到一个列表里查看，每封邮件用彩色圆点标出所属账户
- **草稿同步到服务器**：保存草稿时自动写入服务器草稿箱（可在设置中关闭），删除或发送后同步清理服务器副本，换台设备也能看到草稿
- **协议支持**
  - IMAP + SMTP（推荐，完整文件夹/状态同步）
  - POP3（自研客户端，兼容老旧邮箱）
  - Exchange / Office365（EWS SOAP 接口）
  - OAuth2 授权登录（Gmail、Outlook，PKCE + 回环地址）
- **自动配置发现**：内置 QQ、163、126、Gmail、Outlook、iCloud、腾讯/网易企业邮等预设，未命中时尝试 Mozilla autoconfig、DNS SRV 与端口探测
- **邮件收发**：HTML/纯文本阅读（沙箱 iframe + DOMPurify 消毒，默认拦截远程图片）、回复/全部回复/转发、附件上传下载、草稿箱
- **附件应用内预览**：图片、PDF 直接在窗口中打开，无需先下载到别处
- **邮件标签**：自定义彩色标签（设置 → 标签），阅读窗格一键打标，侧边栏点标签直接筛选，列表行显示颜色圆点
- **导出邮件**：把任意邮件（含附件）导出为标准 `.eml` 文件
- **附件管理器**（设置 → 附件）：集中列出所有邮件的附件，按类型（图片/PDF/文档/压缩包/音视频）和文件名筛选，可打开、另存为或跳回原邮件
- **统计面板**（设置 → 统计）：邮件总量、未读、近 30 天收发趋势图、最常联系人、各账户邮件量
- **本地全文搜索**：SQLite FTS5，中文按字切分，支持跨账户跨文件夹检索
- **过滤规则**：按发件人/收件人/主题/正文匹配，执行标记已读、加星标、移动、删除、免打扰
- **会话视图**：同一主题的往来邮件折叠成一条会话（可在设置中关闭）
- **邮件模板**：常用回复存为模板，撰写时一键插入主题与正文
- **批量导出与打印**：多选邮件批量导出为 `.eml`，单封邮件可直接打印
- **自动翻译**：一键把邮件正文翻译成目标语言（默认中文），内置多个免费通道自动竞速，也支持自定义翻译接口
  - 免费通道有单次长度与每日配额限制，超长正文会自动分段；若频繁失败，建议自建 LibreTranslate 并在设置中填写接口地址
- **富文本撰写**：加粗、斜体、下划线、项目符号、插入链接；文件可直接拖进编辑器作为附件
- **分页加载**：邮件列表滚动到底自动加载更多，邮箱里几千封邮件也不卡顿
- **系统托盘**：托盘图标显示未读数量，可快速打开主窗口或退出（可在设置中关闭）
- **列表密度与栏宽**：邮件列表可切「舒适 / 紧凑」，拖动中间分隔条还能调整列表宽度
- **应用锁**（设置 → 安全）：设置启动密码后，每次打开需先解锁（scrypt 加盐哈希存储）；窗口从托盘重新唤出时也会要求重新解锁
- **自动更新**（设置 → 关于）：启动后静默检查新版本，可直接在应用内下载并重启安装，无需手动换包
- **数据备份与恢复**（设置 → 关于）：一键把数据库与附件备份到指定目录，也可从备份恢复（自动重启、旧数据会先另存一份）
- **mailto 协议**：点网页里的 `mailto:` 链接可直接唤起撰写窗口（预填收件人、主题、正文）
- **界面多语言**：中文 / English 实时切换
- **撤销发送 / 定时发送**：点发送后有撤销窗口（默认 10 秒）；也可打开「自定义时间」精确到某年某月某日某时某分再发（含 1 小时后、今晚 20:00 等快捷项）
- **稍后提醒（Snooze）**：邮件暂时移出收件箱，到点自动回来并提醒（1 小时 / 今晚 / 明天 / 下周一）
- **高级搜索语法**：`from:张三`、`has:attachment`、`is:unread`、`before:2026-01-01`、`in:收件箱`，可存成常驻的「智能文件夹」
- **桌面通知**：新邮件系统通知（可在设置中关闭）
- **托盘与自启**：关闭窗口最小化到托盘、开机自动启动（均可在设置中开关）
- **地址簿**：收发自动收集，撰写时自动补全
- **定时同步**：可配置检查间隔，启动时自动同步
- **IMAP IDLE 实时推送**：新邮件即时到达（可在设置中关闭），断线自动重连
- **撰写自动带签名**：按账户配置签名，写邮件/回复/转发时自动附加
- **阅读窗格布局**：可切换「右侧」或「下方」阅读
- **删除确认**：受设置项控制，避免误删

## 快捷键

| 按键 | 功能 |
| --- | --- |
| `Ctrl/Cmd + N` | 写新邮件 |
| `Ctrl/Cmd + F` | 聚焦全局搜索 |
| `Ctrl/Cmd + Enter` | 撰写窗口中发送 |
| `J` / `↓` | 下一封邮件 |
| `K` / `↑` | 上一封邮件 |
| `R` | 回复 |
| `F` | 转发 |
| `E` | 归档当前邮件 |
| `U` | 标为未读 |
| `S` | 加星标 / 取消星标 |
| `Delete` | 删除当前邮件 |

## 运行方式

### 开发模式

```bash
npm install
npm run dev
```

### 构建与打包

> 推送 `v*` 形式的标签后，GitHub Actions 会自动构建 AppImage 与 deb、生成更新清单并发布到 Release（配置见 `.github/workflows/release.yml`），一般无需本地手动打包。

```bash
npm run build          # 编译到 out/
npm run dist           # 打包 AppImage（输出到 dist/）
npm run dist:deb       # 打包 deb
```

打包产物：`dist/空灵邮箱-0.1.0-x86_64.AppImage`，赋予执行权限后直接双击或命令行运行即可。

```bash
chmod +x dist/空灵邮箱-0.1.0-x86_64.AppImage
./dist/空灵邮箱-0.1.0-x86_64.AppImage
```

### 启动后看不到界面？按顺序排查

1. **缺 FUSE（Ubuntu 24.04 等新发行版常见）**：AppImage 需要 FUSE 才能挂载
   ```bash
   ./dist/空灵邮箱-0.1.0-x86_64.AppImage --appimage-extract-and-run   # 免 FUSE 运行
   # 或安装 FUSE：sudo apt install libfuse2
   ```
2. **透明窗口与合成器不兼容**：默认已关闭透明背景；若你手动开启后窗口不可见/发黑，
   到「设置 → 常规」关闭「毛玻璃透明背景」，或直接删除配置目录后重启：
   `rm -rf ~/.config/空灵邮箱`
3. **看具体报错**：在终端运行（不要双击），终端会打印详细日志
   ```bash
   ELECTRON_ENABLE_LOGGING=1 ./dist/空灵邮箱-0.1.0-x86_64.AppImage
   ```
4. **Wayland 会话**：可强制 X11 模式运行
   ```bash
   ./dist/空灵邮箱-0.1.0-x86_64.AppImage --ozone-platform=x11
   ```

> 说明：国内网络环境下首次安装需为 Electron 配置镜像，例如
> `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/ node node_modules/electron/install.js`

## 添加邮箱

1. 打开应用后点击左侧「添加邮箱账户」（或左下角设置 → 账户）
2. 输入邮箱地址，程序会自动探测服务器配置
3. 选择账户类型（IMAP / POP3 / Exchange），确认服务器地址、端口与加密方式
4. 选择登录方式
   - **密码 / 授权码**：QQ、163、126、Gmail 等需在网页端开启 IMAP/SMTP 并生成**授权码**，用授权码代替登录密码
   - **OAuth2**：需先在 Google Cloud 或 Azure 创建「桌面应用」类型的 OAuth 客户端，填入 Client ID 后点击「在浏览器中授权」
5. 点击「测试连接」确认无误后完成添加，程序会立即开始首次同步

## 数据存储

| 内容 | 路径 |
| --- | --- |
| 数据库 | `~/.config/空灵邮箱/mail.db` |
| 附件 | `~/.config/空灵邮箱/attachments/` |

## 快捷键与操作

- `Ctrl + Enter`：撰写窗口中发送邮件
- 列表支持多选（标记已读 / 加星标 / 移动 / 删除）
- 顶部搜索框为跨账户全文搜索，列表内过滤框仅作用于当前文件夹

## 已知限制

- POP3 账户只同步收件箱，不支持服务器端文件夹与已读状态回写
- Exchange 账户当前使用 Basic / Bearer 认证，未实现 NTLM
- 草稿同步目前只做「本地 → 服务器」单向：在其他客户端新建的草稿不会自动出现在本地
- 「全部收件箱」只聚合各账户的收件箱，其他文件夹仍按账户分别查看
- 自动更新依赖 GitHub Releases：**0.2.1 及更早版本不含更新模块**，需手动下载 0.2.2 一次，之后即可自动升级
- 仅提供 x86_64 安装包（arm64 未构建）
