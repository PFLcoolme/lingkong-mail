功能

日常收发需要的东西，都在

不是玩具演示——这是一套能真正替换你现有邮件客户端的实现。

多账户统一管理

任意数量邮箱并存，支持启用停用、颜色标识与各自的签名。

全协议支持

IMAP / SMTP 完整同步，兼容 POP3 与 Exchange EWS，Gmail、Outlook 可走 OAuth2 授权登录。

全部收件箱

所有账户的来信汇成一个时间流，彩色圆点标出每封信属于哪个邮箱。

离线全文搜索

SQLite FTS5 索引正文与收发件人，中文按字切分，断网也能翻几年前的邮件。

应用锁

密码以 scrypt 加盐哈希存储，启动校验、窗口重新唤出时再次校验，托盘随时一键锁定。

草稿同步到服务器

保存草稿即写入服务器草稿箱，换台设备接着写；删除或发送后副本自动清理。

规则与标签

按发件人、主题、正文自动标记、移动或静音；自定义彩色标签，点一下即筛选。

应用内自动更新

启动后静默检查新版本，下载带进度、校验 sha512，重启即完成升级。

草稿、模板与定时

富文本撰写、常用回复存成模板、撤销发送窗口，也能预约某个时间再发出去。

一键翻译

内置多个免费翻译通道自动竞速，也可填自建 LibreTranslate 接口。

稍后提醒

把邮件暂时移出收件箱，到点自动回来并提醒——1 小时后、今晚、明早或下周一。

备份与迁移

数据库与附件一键备份恢复，单封或批量导出 .eml，附件管理器集中查看。

界面

安静的黑白灰，和一层毛玻璃

无边框窗口、自绘标题栏，浅色为默认；三栏布局可切换阅读窗格位置， 列表支持紧凑与舒适两档密度，栏宽可拖拽并记住。

三栏工作区

账户与文件夹在左，邮件列表居中，阅读窗格在右或下方。

深色模式

跟随系统或用设置固定，毛玻璃在深色下同样通透。

会话视图

同一主题的往来邮件折叠成一条，回复链不再刷屏。

隐私

你的邮件，留在你的机器上

空灵邮箱没有自己的服务器。它直接连接你的邮箱服务商， 邮件正文、附件与索引全部落在本机 SQLite 数据库里。

  • 账户密码用系统密钥环（libsecret）加密，缺失时退化为混淆存储并明确提示
  • HTML 正文在沙箱 iframe 中经 DOMPurify 消毒后渲染，默认拦截远程图片
  • 应用锁密码只存 scrypt 加盐哈希，不保存明文
  • 更新包通过 latest-linux.yml 校验 sha512 后才安装

上手

三步开始收信

  1. 1

    安装并打开

    下载 AppImage 或 deb 包，启动后会看到添加账户的向导。

  2. 2

    填邮箱地址

    内置 QQ、163、126、Gmail、Outlook、iCloud 等 15+ 预设， 填完地址自动带出服务器配置；未命中会依次尝试 autoconfig、DNS SRV 与端口探测。

  3. 3

    用授权码登录

    QQ / 163 这类邮箱需要先在网页端开启 IMAP/SMTP 并生成授权码， 密码栏请填授权码；Gmail 与 Outlook 直接走浏览器 OAuth2 授权。
